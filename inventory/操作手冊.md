# 期初期末庫存資料整理｜同事操作手冊

> 內容審閱稿｜2026-08-28
> 目前先確認文字；確認後再放到工具前台。

## 先看這裡

### 這支工具會做什麼？

把一份期初或期末庫存 Excel 依品名整理成三類，並下載一份新的結果檔，方便後續盤點、查核與留存。

- 一次處理一份 `.xlsx`。
- 期初與期末檔案要分開各操作一次。
- 原始 Excel 不會被修改，也不會上傳到伺服器。

### 結果不代表什麼？

- 不會自動比較期初與期末的增減差異。
- 不會判定會計調整、盤損盤盈或最終庫存金額是否正確。
- 「待人工確認」與「金額未辨識」仍需由同事檢查，不能直接當成已核准資料。

### 核心分類與公式

- 品名依公司最新規則分為「正常商品」、「排除項目」、「待人工確認」。
- 完整品名白名單優先級最高；品名必須完全相同才會套用。
- 若來源檔同時有「實際庫存」與「進貨價」，會計算：
  `實際庫存進貨額 = 實際庫存 × 進貨價`

## 最快操作：5 個步驟

1. 使用公司 Google 帳號開啟「期初期末庫存資料整理」。
2. 等畫面顯示綠色的「集中規則 v版本號」，確認已取得公司最新規則。
3. 按「選擇 `.xlsx` 檔」，選擇一份期初或期末庫存 Excel。
4. 按「開始分析」，等畫面顯示「分析完成」。
5. 確認「列數檢查：通過」，再按「下載結果 Excel」。

下載後會得到另一份檔名含「分類結果」與下載時間的新 Excel；原始檔仍保留不變。

## 操作前要準備什麼？

### 先確認檔案與期間

- 使用 ERP 或公司來源系統匯出的原始 `.xlsx`。
- 先確認這份檔案是「期初」還是「期末」；工具不會自動判斷期間。
- 不要把不同期間的資料先合併在同一份檔案再處理。
- 不要為了讓工具通過而刪除、移動或改寫原始資料；若缺欄位，請保留原檔並回報管理同事。

### 哪些欄位是必要的？

| 欄位或資料 | 是否必要 | 用途 |
| --- | --- | --- |
| 可辨識的「品名」欄 | 必要 | 用於三分類；沒有時會停止分析 |
| 「實際庫存」 | 選填 | 與進貨價一起計算實際庫存進貨額 |
| 「進貨價」 | 選填 | 與實際庫存一起計算實際庫存進貨額 |
| 可安全辨識的庫存金額欄 | 選填 | 用於三類金額加總與排除原因統計 |
| 其他原始欄位 | 不限 | 會完整保留，不改寫欄位內容 |

如果 Excel 有多張工作表，工具會依公司欄位規則找出第一張有品名欄的資料表。分析後請在畫面確認「資料工作表」是否正確。

## 怎麼知道可以繼續？

| 畫面狀態 | 代表意思 | 下一步 |
| --- | --- | --- |
| 「集中規則 v版本號」 | 已取得公司最新規則 | 可選檔並開始分析 |
| 「分析完成」且「列數檢查：通過」 | 所有原始資料列都已分入三類 | 先檢查待確認與金額訊息，再下載 |
| 「這是舊結果」 | 分析後公司規則已更新 | 重新按「開始分析」，不要下載舊結果 |
| 金額欄顯示「未辨識」 | 工具不能安全加總該金額欄 | 可下載分類結果，但不得把未辨識當成 0 |
| 「規則服務無法使用」或紅色錯誤 | 無法確認公司最新規則 | 停止操作，重整頁面；仍失敗時通知管理同事 |

## 三種分類怎麼看？

| 分類 | 白話說明 | 建議處理方式 |
| --- | --- | --- |
| 正常商品 | 未命中排除或待確認規則，或完整品名在白名單內 | 可作為主要商品資料使用 |
| 排除項目 | 品名命中畫面目前顯示的公司排除關鍵字 | 不會刪除，仍保留供查核 |
| 待人工確認 | 品名命中畫面目前顯示的公司待確認關鍵字 | 請同事逐筆確認後再決定；清單為 0 項時不會因這類規則產生資料 |

關鍵字由公司集中管理，可能隨工作需求調整，請以工具畫面當下顯示的最新清單為準。完整品名白名單優先於排除與待確認關鍵字；只有品名完全相同才會套用，多一個字或少一個字都不算。

## 下載檔要看哪裡？

### 建議檢查順序

1. 先開「分類統計」：確認原始總筆數等於三類筆數總和，並查看金額欄辨識結果。
2. 再開「待確認項目」：逐筆檢查品名、判斷原因與命中關鍵字。
3. 接著開「排除項目」：確認排除原因合理，不要刪除這張稽核資料。
4. 最後開「乾淨商品」：作為後續作業的主要商品明細。

### 四張工作表

| 工作表 | 內容 |
| --- | --- |
| 乾淨商品 | 正常商品明細 |
| 排除項目 | 命中排除規則的明細，完整保留供稽核 |
| 待確認項目 | 需要同事人工判斷的明細 |
| 分類統計 | 原始筆數、三類筆數、可安全辨識的金額加總與排除原因統計 |

前三張明細表會保留所有原始欄位，另外新增「實際庫存進貨額」、「分類結果」、「判斷原因」、「命中的關鍵字」。

每張明細表最後都有深色、粗體的「合計」列，顯示該表資料筆數、可安全辨識的庫存金額與實際庫存進貨額合計。

## 「實際庫存進貨額」要注意什麼？

- 有「實際庫存成本額」時，新欄會放在該欄後；沒有時會放在原始欄位後。
- 明細列會保留 Excel 公式，最後的合計列也會加總。
- 若缺少「實際庫存」或「進貨價」，新欄與合計列會標示「未辨識進貨價」，不會自行猜價格。
- 如果兩欄都存在，但個別資料格是空白或無法相乘的內容，該列公式會顯示 0；請回頭檢查該列原始數值，不要直接當成確定的零庫存金額。

## 什麼情況要重新操作？

- 換了另一份期初或期末 Excel：重新選檔後再按「開始分析」。
- 畫面顯示「這是舊結果」：公司規則已變更，必須重新分析。
- 修正了來源 Excel：另存一份新檔後重新選檔，不要覆蓋原始匯出檔。
- 「列數檢查」不是「通過」：不要下載或使用結果，請保留畫面訊息並通知管理同事。

## 常見問題

### 找不到品名欄位

確認表頭中是否有「品名」或公司已設定的其他品名欄名。不要直接移動或刪除原始資料；請把畫面訊息提供給管理同事確認。

### 規則服務無法使用

先重新整理頁面再試一次。工具為避免不同同事使用不同規則，無法取得最新版時會禁止分析。若仍失敗，請通知管理同事。

### 沒有出現庫存金額合計

代表工具無法安全確認庫存金額欄，或該欄內容不是可安全加總的數字。工具不會猜測；請保留原檔並通知管理同事。

### 下載後找不到檔案

請查看瀏覽器的「下載項目」或電腦的「下載」資料夾。新檔名會包含「分類結果」和下載時間。

## 分類不符預期怎麼辦？

一般同事只能查看最新規則。只有公司指定的規則管理者可以進入「管理規則」頁新增、刪除或發布規則。

請記下並提供：

- 品名
- 目前被分到哪一類
- 希望分到哪一類
- 畫面顯示的集中規則版本

再交由規則管理者判斷是否調整關鍵字或完整品名白名單。不要傳送整份真實庫存檔給不需要取得資料的人。

## 資料安全

- Excel 只在目前瀏覽器分頁內讀取、整理與產生新檔。
- 網站不會上傳 Excel、檔名、商品列資料或輸出內容。
- 工具只會向同網域讀取公司集中分類規則。
- 輸出會另存成新檔，不會覆蓋原始 Excel。

如果遇到無法解決的問題，請保留原始檔，記下畫面訊息、使用的規則版本與操作步驟，再通知管理同事。
