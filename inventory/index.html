期初期末庫存資料整理

三步整理庫存，原始檔安心保留

選一份期初或期末 `.xlsx`，工具會在這個瀏覽器分頁內找出品名欄、完成三分類，並產生一份新的 Excel。檔案不會上傳，也不會改動原始檔。

1
選擇 Excel從自己的電腦選擇庫存檔。
2
開始分析自動找品名欄並顯示分類統計。
3
下載新檔保留全部資料，新增實際庫存進貨額，明細表最後附合計。

操作手冊

先了解這支工具會做什麼、怎麼判斷完成；需要時再展開下方說明。

約 2 分鐘
用途

分開整理期初或期末庫存

一次選一份 `.xlsx`，依品名整理成正常、排除與待人工確認三類，再下載新檔。

不代表：工具不會比較期初與期末差異，也不代表會計核准。

核心公式

實際庫存進貨額

實際庫存 ×乘以 進貨價

只有兩個欄位都能辨識時才會計算；缺欄位時會標示未辨識，不會猜測。

最快操作：5 個步驟

  1. 1開啟工具使用公司 Google 帳號。
  2. 2確認規則等待顯示「集中規則 v版本號」。
  3. 3選擇 Excel選一份期初或期末 `.xlsx`。
  4. 4開始分析等待畫面顯示「分析完成」。
  5. 5檢查並下載確認列數檢查通過，再下載新檔。
操作前要準備什麼？
  • 使用 ERP 或公司來源系統匯出的原始 `.xlsx`；舊式 `.xls` 或 CSV 不能直接使用。
  • 先確認檔案是「期初」還是「期末」；工具不會自動判斷期間。
  • 期初與期末要分開處理，不要先合併成一份檔案。
  • 不要為了讓工具通過而刪除、移動或改寫原始資料。
欄位或資料是否必要用途
可辨識的「品名」欄必要用於三分類；沒有時會停止分析。
「實際庫存」與「進貨價」選填兩欄一起用於計算實際庫存進貨額。
可安全辨識的庫存金額欄選填用於三類金額加總與排除原因統計。
其他原始欄位不限工具會完整保留，不改寫欄位內容。

多張工作表：工具會找第一張有品名欄的資料表。分析後請確認畫面的「資料工作表」是否正確。

下載後，四張工作表要怎麼看？
  1. 分類統計：先確認原始總筆數等於三類筆數總和，再看金額欄辨識結果。
  2. 待確認項目：逐筆檢查品名、判斷原因與命中關鍵字。
  3. 排除項目：確認排除原因合理，保留這張稽核資料。
  4. 乾淨商品：作為後續作業的主要商品明細。

乾淨商品正常商品明細。
排除項目命中排除規則的明細，完整保留供稽核。
待確認項目需要同事人工判斷的明細。

前三張明細表會保留所有原始欄位，另外新增「實際庫存進貨額」、「分類結果」、「判斷原因」與「命中的關鍵字」。

三張明細表最後都有深色粗體的「合計」列，顯示資料筆數、可安全辨識的庫存金額與實際庫存進貨額合計。

三種分類與白名單要怎麼看？
分類白話說明建議處理
正常商品未命中排除或待確認規則，或完整品名在白名單內。可作為主要商品資料使用。
排除項目品名命中畫面目前顯示的公司排除關鍵字。不會刪除，仍保留供查核。
待人工確認品名命中畫面目前顯示的公司待確認關鍵字。請同事逐筆確認後再決定；清單為 0 項時不會因這類規則產生資料。
以畫面最新清單為準：關鍵字由公司集中管理，可能隨工作需求調整。完整品名白名單優先於排除與待確認關鍵字；品名必須完全相同，多一個字或少一個字都不算。
「實際庫存進貨額」與合計要注意什麼？
  • 有「實際庫存成本額」時，新欄會放在該欄後；沒有時會放在原始欄位後。
  • 明細列會保留 Excel 公式，最後的合計列也會加總。
  • 缺少「實際庫存」或「進貨價」時，會標示「未辨識進貨價」，不會猜價格。
  • 兩欄都存在，但個別資料格空白或無法相乘時，該列公式會顯示 0；請回頭檢查原始數值。
遇到錯誤或分類不符預期怎麼辦？

找不到品名欄

不要直接移動或刪除原始資料。請保留原檔，把畫面訊息提供給管理同事確認。

規則服務無法使用

重新整理頁面再試一次。仍失敗時通知管理同事；工具會禁止分析，不會偷用舊規則。

沒有庫存金額合計

代表工具無法安全辨識金額欄。可保留分類結果，但不要把未辨識當成 0。

下載後找不到檔案

查看瀏覽器的「下載項目」或電腦的「下載」資料夾。新檔名會含「分類結果」與下載時間。

分類不符預期

請記下「品名、目前分類、希望分類、集中規則版本」，再交由規則管理者處理。一般同事只能查看規則，不能自行發布。

網站不會上傳 Excel、檔名、商品列或輸出內容；結果另存新檔，不會覆蓋原始 Excel。
