# 公司工具即時操作指引

發布版本20261102-company-guidance-r1；隔離checkout已整合最新正式62c4691，使用者已授權部署。

各工具主頁在麵包屑下方有跟隨捲動的「即時操作指引」，依目前資料與狀態說明下一步。按「前往這一步」只移動畫面與鍵盤焦點，必要時展開收合區；不會代按分析、授權、儲存、核准或付費AI。操作後請看原按鈕旁與指引內的狀態訊息。指引不代表已保存或已核准。

共用元件app.js／style.css由同源載入；各app以唯讀provider提供當前狀態與可見目的地，不暴露訂單內容、Excel、憑證或token。主流程依角色、資料就緒、結果及原有disabled／hidden狀態提示。版本manifest以no-store取得；失敗或不符時停用操作，更新須使用者自行確認重新載入。核心計算函式、Excel讀寫設定與後端授權維持原樣。

範圍：庫存資料整理、成本稽核、供應商對帳、競品分析、採購規劃、週補貨調撥，以及各自互動規則管理頁；門市訂單保留原生指引，最高權限設定頁補共用指引。列印紙本及純閱讀手冊不顯示額外指引；公開訪客仍使用已自包含的原生指引，不請求公司專用共用資產。

新增工具需以CompanyGuidance.register註冊resolve與statuses。resolve只返回標題、提示與實際存在／授權可見的target。狀態提示由原操作DOM更新，不以按鈕被點擊判定成功。可見角色、既有版本保護與後端驗證是權威來源。共用工具核心原則由專案集中SKILL.md及AGENTS.md維護。

## 2026-11-02 進度與原生選檔

共用指引以本機progress.js記錄實際訊息或完成量的最後更新時間；相同訊息及每5秒畫面更新不刷新時間。處理中30秒沒有新進度提示等待，不判定失敗；完成、錯誤、授權各自顯示。progress()只提供有實際總量的完成量，主採購區分選檔類數與真正讀取份數，不將讀檔百分比當整體計算完成率。reportProgress()只更新本機顯示，不發業務請求。

原生選檔返回觸發focus檢查時，change先暫存至版本確認成功，且須同一選取、仍連接且未停用才交還原處理；失敗、過期及已被新選檔取代不重送。點擊與表單防護保持。新增進度元件須先於app載入，所有管理頁與script版本探測頁同步版本。
